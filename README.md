
# Supply Chain Shocks

This repository hosts the shipping cost surprise series and estimated supply chain shocks from:

Känzig, Diego R. and Raghavan, Ramya (2026).  
*The Macroeconomic Effects of Supply Chain Shocks: Evidence from Global Shipping Disruptions.*  
Ungated version: https://dkaenzig.github.io/diegokaenzig.com/Papers/kr_supplychainshocks.pdf

Disclaimer: The data is preliminary and still subject to change.

## Data

The surprises and shocks are stored in the file  

[supplyChainShocks.xlsx](supplyChainShocks.xlsx)

The file contains:

| Variable | Description |
|----------|-------------|
| Shipping Surprise Series | Monthly shipping cost surprise series obtained by aggregating daily surprises. |
| Supply Chain Shock | Supply chain shock identified using an external instruments VAR, where the surprise series serves as an instrument for the BDI residual. |
